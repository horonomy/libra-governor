Privacy

Libra is local-first. Its product operation stores task state and ledger data on your machine. Prompts, source code, and tool output are not sent to Libra-operated services by default.

The optional gateway handles only traffic you explicitly route through it, to enforce provider spend limits. Libra does not run analytics on this site, collect prompts, inspect authenticated content, or collect repository names, tenant identities, emails, secrets, or security payloads.

For support, use the public GitHub issue tracker. Do not include sensitive content in an issue.
