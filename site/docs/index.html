Libra Governor documentation

Install from source

Libra does not publish prebuilt binaries or a hosted installer. Clone the public repository and run the product-owned installer:

git clone https://github.com/horonomy/libra-governor.git
cd libra-governor
./scripts/install.sh

The installer builds the CLI with Cargo, installs local hooks, and runs libra-governor doctor. Review the script and its changes to your local Claude settings before running it.

Claude Code and Codex

Claude Code is the established integration. Codex support is available through the Agent Adapter contract, with capability differences documented honestly in the repository's Codex integration guide.

Data boundary

Full prompts, source code, and tool output remain local by default. The optional gateway only sees traffic explicitly routed through it and enforces provider spend; it is not a general LLM router.

Preview limits

This is a Developer Preview. It has no hosted control plane, uptime commitment, account system, or production support SLA.
