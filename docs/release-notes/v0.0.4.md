# Libra Governor v0.0.4 — Cooperative Preview (Apple Silicon macOS)

A local monthly budget shared by your Claude Code sessions and subagents. **While the Libra daemon and hooks are running correctly**, prompts are admitted or refused up front against a monthly USD cap you set
(`libra-governor shared-budget init --monthly-usd <n> --time-zone <IANA>`). **This is a Cooperative Preview, not a hard spending cap.**

What it is and is not (the five required disclosures, then the fail-open and trust-boundary disclosures):
1. **Admission-bounded (cooperative), not a strict monetary cap.** A prompt is admitted only if the remaining monthly budget can cover its hold, and only when the daemon and hooks answer.
2. **In-turn overshoot is possible.** Spend inside a turn is visible only when the turn stops, so a turn can cost more than its hold.
3. **Codex is not gated.** Codex sessions are neither admitted nor charged by this budget; there is no gateway hard cap in this release.
4. **Amounts are Libra's list-price-equivalent estimates (or flat holds), never your provider bill or quota, and they are not exact.** The pinned pricing table has known errors in both directions, and they change how accurately the budget admits and refuses prompts:
   - The 1-hour cache-write tier is not modelled. Those tokens are priced at the 5-minute rate, so that spend is **under-accounted**.
   - The fast-mode premium and the `inference_geo` multiplier (1.1x, US-only) are not modelled, so spend on such requests is **under-accounted**.
   - Haiku 5.5 prompts under 100k tokens are priced at the over-100k rate, so they are **over-accounted by approximately 5x**.

   The cap is a Libra-accounted estimate that can drift from the provider bill either way. It is not a guarantee of matching the bill or of staying under your plan or provider limit.
5. **Accounting boundary.** Only Claude Code sessions and subagents whose settlement hooks run and whose transcripts can be read and attributed are counted. Other executors and unreadable or unattributed spend can settle at the flat hold, be recorded as unattributed, or be missed. Turns around `/compact`, partly flushed interactive turns, subagent files over 32 MiB, and settlement skipped while the daemon is down can also be under-counted or missed. A forward clock jump or time-zone change near a month edge opens the next month's budget early.
6. **Fail-open behaviour when the daemon is unavailable.** With a budget configured, an unreachable daemon makes the prompt-admission hook refuse the prompt (observed in testing with daemon auto-start disabled). The other hooks fail open: tool-call checks are not enforced, and end-of-turn and end-of-session settlement is skipped with only a log line. A skipped settlement may be recovered by a later successful end-of-turn settlement in the same session, or it may never be counted. Prompts whose session id Libra cannot use are never blocked, and a budget file that cannot be reached is treated as no budget.
7. **Libra is NOT a security boundary against a governed agent running under the same operating-system user.** Libra and the agent it governs run as the same user. Any process under that user, including the governed agent, can stop the daemon, edit or delete `shared-budget.json`, or send the daemon requests. The cap is cooperative and not tamper-proof, and Libra offers no protection against an active, adversarial agent running as your user. Keep Libra's state directory in its default private location, and do not place it, or point `LIBRA_GOVERNOR_STATE_DIR`, in a shared location or any location that other users can write to.

Other known limits:
- **`shared-budget init --force`** replaces the whole budget file with no backup. Hand-written `pricing_overrides`, the subagent unmeasured charge and soft limits that you do not pass again are dropped, and the turn hold resets to its default if omitted.
- **Hook ownership.** `uninstall` can miss a hook command that was hand-quoted or renamed, and `install` can then add a duplicate. Reinstalling from a different binary path can leave a second hook set; no double charge was found in source review, but legacy tool-call counts double, and an older hook set could book the flat hold (inferred, untested). `install` refuses a binary path containing whitespace or a shell metacharacter, because Claude Code would run such a hook command through a shell and it would silently never run.
- **Clock anomaly.** After a forward clock jump creates a later month's pool, every prompt is refused (`clock_anomaly`) and there is no repair command. Correcting the clock does not clear it; the recovery steps are in ADR-0026, and deleting `shared-budget.json` pauses the budget.
- **Settlement sweep limits.** The end-of-turn sweep visits at most 64 subagent transcript files and 128 MiB per run, so records can be deferred or lost. A subagent file over 32 MiB is booked at the flat hold and not re-measured. Libra refuses to record a single charge above ten times the monthly cap in its own ledger; this concerns only Libra's accounting and does not mean the provider refuses, cancels or changes what it actually bills.
- **Late records.** Late transcript evidence may be recovered by a subsequent Stop or SettleTail where supported, but windows that were already settled are not guaranteed to be re-measured. A turn whose transcript could not be read at settlement is booked at the flat hold; its late lines may be lost (the hold already covers them) or counted again on top of the hold at the next settlement.
- **Flush timing.** Transcript flush timing was measured only against a fake upstream (four interactive samples, plus earlier non-interactive runs). That evidence says nothing about real-provider latency, and no real-provider latency coverage is claimed.

Support: **Apple Silicon (aarch64) macOS only.** x86_64 macOS, Linux and Windows are not supported or verified.

What was tested, and what was not:
- Independently reviewed, **test-owned** evidence with synthetic inputs. The real Claude Code 2.1.306 binary was driven interactively against this build's real hooks and daemon, but against a **fake loopback upstream** with synthetic usage inside a network-deny sandbox. That exercised hook timing, admission, settlement, denial messages and recovery. It involved **no real provider, no real billing or quota, no real model latency and no production observation.** Accounting accuracy against real provider usage has not been measured.
- Install, uninstall and budget behaviour were verified on a clean second macOS user account on one Apple Silicon Mac, and the release artifact's provenance and lifecycle were verified in isolation. This is **not** a fresh-machine qualification.
- **Not verified:** genuine provider billing or quota and real-provider latency or usage (including after `/compact`), production use, a fresh-machine install, rollback of a published release artifact, and hook process isolation (no lingering processes, write footprint of hooks run without a daemon) on this build.

**Uninstall does not restore your Claude Code `settings.json` byte-for-byte.** It removes only Libra's entries and preserves your other keys and hooks, but it re-serializes the file. Install writes a byte-identical backup first (`settings.json.libra-backup-*`); keep it if you need the exact original. Uninstall also leaves timestamped backup files and a `settings.json.horonom-write.lock` file next to your settings: the backups are your rollback copies (keep or delete them), and the lock file is only Libra's own write lock. Local export and prune are local-only; nothing is uploaded. No telemetry.

Not in this release: S11 gateway hard cap, Codex budget gate, OpenAI Responses gateway, remote upload, strict cross-host cap. No claim is made about real-provider pacing or productivity gains, production-observed correctness, or native Codex budget enforcement.

Known issues in this preview: three open dependency alerts concern a Python experiment directory (`experiments/phase0`) that is not part of the shipped binary. `libra-governor uninstall` always suggests `cargo uninstall libra-governor-cli`; if you installed from the tarball, delete the copied binary yourself.

Artifact: `libra-governor-aarch64-apple-darwin.tar.gz` with sha256 and GitHub build-provenance attestation (`gh attestation verify <file> --repo horonomy/libra-governor`).
